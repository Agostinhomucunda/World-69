# Imagens dos cursos

Imagens obtidas via pesquisa de imagens a partir de páginas identificadas como Unsplash; redimensionadas para 900×600 e otimizadas em WebP para o site.

- `ethical-hacking.webp` — fotografia de cibersegurança / ethical hacking.
- `programming.webp` — fotografia de código num portátil.
- `graphic-design.webp` — fotografia de design gráfico e ferramentas criativas.
- `canva.webp` — espaço de trabalho criativo.
- `social-media.webp` — fotografia de análise de redes sociais.
- `import-export.webp` — fotografia de transporte marítimo e contentores.

Os cartões usam texto alternativo descritivo e mantêm as imagens como assets locais para não depender de links temporários da pesquisa.
